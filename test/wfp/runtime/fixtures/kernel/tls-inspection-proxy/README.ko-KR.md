# 커널 TLS 검사 허용성 픽스처

이 디렉터리는 커널 TLS 프록시의 제어된 원본 서버/클라이언트, 잘못된 형식·유휴 입력과
판정만 소유합니다. 인접한
`crtsys_wfp_kernel_tls_inspection_proxy_controller.exe`를 시작하며, 드라이버
설정·임시 머신 인증서·WFP 정책은 컨트롤러만 담당합니다.

픽스처는 HTTP/1.1·HTTP/2 허용/차단, IPv4/IPv6, SNI·ALPN, 요청·응답 변환,
잘못된 형식과 시간 초과 실패, 제한된 캡처 레코드, 명시적 정책 제거, 직접 연결
복원과 정리를 검증합니다. 마지막에 컨트롤러 통계를 판정하고 PASS를
출력합니다.

픽스처에는 WFP 관리, 드라이버 IOCTL, 서비스 제어 호출이 없습니다.
